# GOLPE

Jogo original de crime em mundo aberto (Vila Rubra). Protótipo v0.1.

- **Jogar no navegador / iPhone:** https://rezyto.github.io/golpe/ (Safari → Partilhar → Adicionar ao ecrã principal)
- **Android:** descarregar `golpe.apk` em [Releases](https://github.com/rezyto/golpe/releases/latest)
- **Atualizações:** automáticas no ecrã de login (lê `web/version.json`).

Estrutura: `web/` jogo · `app/` casca Android (Capacitor) · `PLANO.md` plano e roadmap.

Lançar uma versão: subir `GAME_VERSION` em `web/index.html` e `version` em `web/version.json`, fazer push.
